# Introduction

Svelte Chanhdai is a collection of reusable Svelte components ported from Chánh Đại's original work.

## Inspiration

Inspired by [Chánh Đại's portfolio](https://chanhdai.com). Ported to Svelte by [Bhide Svelte](https://bhide.dev).
