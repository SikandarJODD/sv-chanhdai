# Code of Conduct

## Our pledge

We want this project to be a welcoming, safe, and respectful place for everyone, regardless of background, identity, experience, or ability.

## Expected behavior

- Be kind, patient, and respectful.
- Give useful feedback and accept it with care.
- Respect different ideas, experiences, and skill levels.
- Focus on what is best for the project and its community.

## Unacceptable behavior

- Harassment, threats, insults, or discrimination.
- Sexualized language or unwanted attention.
- Sharing someone else's private information without permission.
- Trolling, personal attacks, or repeated disruption.

## Reporting

If you experience or witness unacceptable behavior, contact the project maintainers privately through GitHub. If no private contact option is available, open an issue asking how to reach a maintainer, but do not include sensitive details in the issue.

Maintainers will review reports fairly, keep details private where possible, and take appropriate action. This may include a warning, removing content, or temporarily or permanently banning someone from the project.

## Scope

This code of conduct applies in project spaces and whenever someone is representing the project in public.
